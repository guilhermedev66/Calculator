# Calculator

Projeto de estudo desenvolvido para praticar lógica de programação, estruturas condicionais e manipulação de entrada de dados em aplicações de console.

## Funcionalidades

- Soma
- Subtração
- Multiplicação
- Divisão

## Tecnologias

- C#
- .NET 10
- Console Application

## Como Executar

```bash
dotnet run
```

O programa exibe um menu no console. Digite o número da operação desejada e informe os dois valores solicitados.

## Melhorias Futuras

- Validação de entrada (hoje o programa encerra com erro se o valor digitado não for um número válido)
- Tratamento de divisão por zero (atualmente retorna `Infinity` sem mensagem amigável)
- Uso de `decimal` no lugar de `float` para maior precisão
